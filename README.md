# 💰 Daily Expense Analyzer

A simple Java-based console application to record, manage, and analyze daily expenses. This project demonstrates the practical implementation of Object-Oriented Programming (OOP), Data Structures, Algorithms, and File Handling.

## 📌 About the Project

The Daily Expense Analyzer helps users maintain a record of their daily spending. It provides functionalities to add expenses, display records, search expenses by category, sort expenses by amount, calculate total spending, and identify the highest expense.

The application uses Java's `ArrayList` for dynamic storage and a text file for persistent data storage.

## ✨ Features

- ➕ Add new expenses
- 📋 Display all expenses
- 🔍 Search expenses by category
- 📊 Sort expenses in descending order of amount
- 💰 Calculate total expenses
- 🏆 Find the highest expense
- 💾 Save and load expense records using file handling
- 🔢 Automatically generate expense IDs

## 🛠️ Technologies Used

```bash

```

### 2. Navigate to the project directory



## 📊 Sample Operations

## 💾 Data Storage

Expense records are stored in `expenses.txt` using a file-based storage mechanism. Existing records are loaded when the application starts, and updated records are saved when the application exits.
